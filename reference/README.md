# Option reference snapshot

`asa-options.json` is a snapshot of every server option ARK: Survival Ascended documents,
parsed out of the community wiki's own annotated default `Game.ini` and `GameUserSettings.ini`
(https://github.com/Arkobat/ArkServerSettings, `SurvivalAscended/Default/`, which is generated by
a scraper run against https://ark.wiki.gg/wiki/Server_configuration). Captured 2026-09-08.

Each entry carries the key, which file and ini section it belongs to, its documented default, its
value type, and the wiki's own description. Nothing in this file is hand-edited, so it stays a
faithful copy of the upstream documentation and can be re-fetched and diffed.

It exists so option coverage is a checkable fact rather than an assumption:
`node tools/check-coverage.js` asserts that every key here is either a curated field in
`lib/settings-fields.js` or an explicitly declared raw-INI-only option with a stated reason. A key
that is neither fails the check, which is what catches a new ARK release adding options.

346 options: 212 across GameUserSettings.ini, 134 in Game.ini.
